# Stage 2.1 — Technician-friendly spike watch

- Duration options: 1, 3 (default), 5, 10, 30 minutes.
- Live watch-specific CPU/memory/disk graph, separate from health-check graph.
- Stop & Analyze summarizes peak and average utilization from samples already collected.
- Spike process snapshots retained in browser memory; local JSON export includes process names if spikes occurred. Treat exports as sensitive.
- This is a browser-tab monitor, not a background service. The graph resets on starting a new watch or reloading the page.
- No automatic cloud AI transmission. Ask PC Medic does not yet consume watch reports automatically.
