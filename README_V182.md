# PC Medic AI V1.8.2 — Concise AI Results

- Cloud AI providers are instructed to return a brief Summary and What to do next (under 120 words).
- Main AI response shows the short result; Show detailed analysis retains the full provider text.
- Offline responses receive a compact preview and retain full guidance in details.
- No changes to the Windows collectors, one-click health check, consent flow, or provider keys.

## Run

In the extracted pc-medic-ai folder: `python -u dashboard.py`. Refresh the browser with Ctrl+Shift+R.

## Notes

Cloud model formatting is not guaranteed; a short fallback preview is shown if it ignores the headings. Results are evidence-based, not a guarantee of system health.
